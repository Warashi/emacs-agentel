# Spec test cases

`expected.eld` holds the examples of these specs with the tree a parser
is expected to give for each, generated by `convert.py` (`make spec`):

- `commonmark-0.31.2.json`: [CommonMark Spec](https://spec.commonmark.org/0.31.2/)
  0.31.2 by John MacFarlane
- `gfm-27d942c.txt`: [GitHub Flavored Markdown Spec](https://github.github.com/gfm/)
  0.29-gfm, from [cmark-gfm](https://github.com/github/cmark-gfm/blob/27d942c8b0a62d192f616e5bf3578f4b6a89e180/test/spec.txt)
- `cjk-friendly-e9762c3.json`: the test cases of
  [markdown-cjk-friendly](https://github.com/tats-u/markdown-cjk-friendly/tree/e9762c379b36ce5ee0e9b185fae9a908244f598b/testcases),
  with the HTML its remark plugins give, rendered by `cjk-friendly.mjs`

Both specs are licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/),
and so are their files above and the examples of `expected.eld` adapted
from them.  The test cases of markdown-cjk-friendly, their file above and
the examples adapted from them are under the MIT license in
`../../etc/LICENSE-markdown-cjk-friendly`.

`convert.py` leaves out the examples that need raw HTML to be taken as
HTML, and the CommonMark examples that GFM autolinks turn into links.
